# Vibe Eletronics · Media kit

Página de apresentação e materiais de marca da Vibe Eletronics (assistência técnica de celulares em Armação dos Búzios, RJ): logos, cores, tipografia, flyer para impressão e artes para redes sociais.

Publicada com GitHub Pages.

## Como atualizar

- `index.html`: a página.
- `fontes/`: modelos dos logos e das artes (`logo.html`, `social.html`) e o script que gera tudo.
- `python fontes/gerar.py`: refaz logos, artes, prévias, zips e o PDF. Precisa do Microsoft Edge e do Pillow.
- `python fontes/gerar.py pdf`: refaz só o PDF da página.
